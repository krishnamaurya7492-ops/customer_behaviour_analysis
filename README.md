# customer_behaviour_analysis
End-to-end Customer Shopping Behavior Analytics project using Python, SQL Server, and Power BI to clean, analyze, and visualize 3,900 customer transactions and uncover actionable business insights.

The project follows a complete analytics workflow — from data cleaning and feature engineering in Python, to business analysis using SQL Server, and finally interactive dashboard development in Power BI.

🛠️ Tech Stack
Python — Pandas, NumPy
SQL Server — Data storage & business analysis
Power BI — Interactive dashboard & visualization
Jupyter Notebook — Data preparation and exploration
🔄 Project Workflow

Raw Data → Python → SQL Server → Power BI → Business Insights

Data Exploration & Cleaning
Explored the dataset using Pandas
Identified and handled missing values
Standardized column names
Created additional analytical features such as age_group and purchase_frequency_days
Removed redundant information after consistency checks
SQL Analysis
Used SQL Server to answer business questions around:
Revenue by gender
High-spending discount users
Top-rated products
Shipping preferences and spending
Subscriber vs. non-subscriber performance
Discount-dependent products
Customer segmentation
Top products within each category
Repeat buyers and subscription behavior
Revenue contribution by age group
Power BI Dashboard
Built an interactive dashboard to visualize:
Customer and revenue KPIs
Subscription distribution
Revenue and sales by category
Age-group performance
Interactive customer segmentation and filtering
📊 Dataset

The dataset contains 3,900 customer purchase records across 18 columns, covering customer demographics, purchase information, product categories, discounts, subscriptions, shipping, ratings, and purchasing frequency.

💡 Key Objective

The objective was not just to create visualizations, but to demonstrate a complete data-to-decision workflow — transforming raw transactional data into structured analysis and ultimately into business-oriented insights and recommendations.

📌 Business Recommendations

The analysis supports recommendations around:

Increasing subscription adoption
Strengthening customer loyalty programs
Reviewing discount strategies
Promoting top-rated and best-selling products
Targeting high-revenue customer segments
